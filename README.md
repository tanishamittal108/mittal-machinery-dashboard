# 📊 Mittal Machinery Sales Dashboard

An interactive Power BI dashboard built to analyze sales performance, vendor activity, and revenue trends for Mittal Machinery, a machinery and lubricants trading business.

## 🚀 Project Overview

This dashboard provides business insights by analyzing sales transactions, vendor performance, and regional distribution using Power BI, DAX, and Power Query.

### Key Objectives
- Track revenue and order performance
- Monitor vendor contributions
- Analyze brand-wise sales trends
- Evaluate cancellation behavior
- Compare city-wise business performance
